Why PScanner.

Small, quick and made for the way you actually study.

Right file names.

Files are saved with the title the portal shows, like PPT_ch1, instead of long random IDs.

Only what you open.

Background loads are ignored. Your list holds just the material you actually viewed.

Download all.

Opened five chapters? Grab every file in one click, with no duplicates.

Private by design.

Everything stays in your browser. Nothing is sent to a server, and no logins are bypassed.

Install in a minute.

PScanner isn’t on the Chrome Web Store yet, so you load it once by hand.

Download and unzip

Get pscanner.zip and extract it. You’ll get a folder named pscanner.

Open Chrome’s extensions page

Go to chrome://extensions and switch on Developer mode (top right).

Load unpacked

Click Load unpacked and choose the pscanner folder, the one with manifest.json inside.

Allow it on the portal

Open the e-learning portal, click the orange PS icon (pin it from the puzzle menu) and press Allow on this site.

Open material, then download

Open any PDF or slides on the portal, press Refresh in the panel and hit Download.

Questions.

Does it bypass the portal’s login or protection?

No. PScanner only sees files your own browser already receives while you’re signed in. If a file is locked or a link has expired, it can’t download it.

Is it safe?

It runs only on the portal and its file hosts, stores nothing outside your browser session, and is a handful of plain JavaScript files you can read yourself before loading.

Why Developer mode?

Because it’s loaded from a folder instead of the Chrome Web Store. Chrome may remind you about this when you start it. That’s normal.

Does it work on phones or other browsers?

It’s built for desktop Chrome. Other Chromium browsers such as Edge and Brave usually work too.

A file shows a random name or doesn’t appear. What now?

Reload the portal tab once after installing, open the material, wait a moment and press Refresh. The name comes from the title shown above the viewer.
